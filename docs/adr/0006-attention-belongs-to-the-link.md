# Attention belongs to the Link, not to the External Object

A pull request tracked by two Items is one External Object but two separate commitments, so "I have reviewed this" is recorded on the Link — the pairing of one Item with one External Object — and each Link carries its own watch policy. Deduplication applies to fetching and to the Activity record, never to attention: marking a change reviewed on one Item must not silently clear it on another, because that would drop a commitment the user never released.
