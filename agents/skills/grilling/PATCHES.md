# Patches

## Question numbering runs across rounds

- **Change:** before the round format, a bold rule says numbering runs across the whole session (round two opens at the next unused number, with a Q1–Q3 → Q4 example); the format template uses `Q<n>` / `Q<n+1>` instead of the literal `Q1` / `Q2`.
- **Why:** weaker models copied the literal `Q1` / `Q2` into every round, so numbers repeated across rounds and answers like "Q2: yes" became ambiguous.
